# Dropbox Plugin for CrossPoint

Official repository for the Dropbox plugin for CrossPoint and reTerminal Sticky e-readers.

## Overview
This plugin allows browsing and downloading ebooks and documents directly from your Dropbox account.

- **Author:** [loitq07](https://github.com/loitq07)
- **Compatibility:** CrossPoint firmware with Plugin API 1+
- **Formats:** EPUB, PDF, TXT, MOBI, CBZ

## Installation

### Via Plugin Hub
1. On your CrossPoint / Sticky device, open **Plugins** > **Plugin Hub**.
2. Locate **Dropbox** in the Community catalog and tap **Install**.

### Manual Installation
Copy the `dropbox.crosspoint-plugin` directory into `/.crosspoint/plugins/dropbox/` on your device's SD card.
